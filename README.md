# houseofkathy.com

A modern web project built with Astro, Svelte, and TypeScript.

### Tech Stack
Astro
Svelte
TypeScript

### Getting Started
```git clone https://github.com/your-username/houseofkathy.git
cd houseofkathy
npm install
npm run dev
Build
npm run build
```

### Deployment
Planned deployment using Cloudflare for fast, global delivery.

### Notes

This project is a work in progress and will continue to evolve with new features and improvements.
